Two accounts. Same app.
Side by side.

DoppelDock gives an app on your Mac a second copy with its own sign-in and its own coloured Dock icon. Your work and personal accounts, open at the same time.

Download DoppelDock (.dmg)

Drag DoppelDock to Applications and open it. It isn't notarized by Apple, so the first time, go to System Settings › Privacy & Security and click Open Anyway.

brew install zarinlab/tap/doppeldock && doppeldock install

Installs the doppeldock command and adds the DoppelDock app to Applications. No warnings.

d=$(mktemp -d) && curl -fsSL https://github.com/ZarinLab/doppeldock/releases/latest/download/doppeldock -o "$d/doppeldock" && bash "$d/doppeldock" install

Open Terminal, paste this line and press Return. No warnings, nothing else to install.

Free and open source (MIT) · macOS 12 or later

How it works

Three steps, about a minute.

1

Install

Download the app, or use Homebrew or the Terminal line above. DoppelDock appears in your Applications folder.

2

Make a profile

Open DoppelDock, click New Profile…, pick the app, type a name such as Personal, click Create.

3

Sign in

Open the new app, sign in with your other account, and keep it in the Dock.

Tell them apart at a glance

Works with apps built on Electron, such as Claude, Slack, Discord, Visual Studio Code, Figma, Signal and draw.io.

Its own Dock icon

Each profile gets a recoloured icon, a letter badge, or both, and can keep that icon in the Dock while it is open.

Light or Dark per profile

Open your work copy in Dark and your personal copy in Light, whatever your Mac is set to.

Separate sign-in

Each profile keeps its own sign-in, settings and local data. The original app is never changed.

Keeps itself up to date

Update the original app as usual; profiles follow it the next time you open them.

Safe by design

Removing a profile moves it to the Trash, and its sign-in is kept unless you choose otherwise.

Command line too

Everything the app does is also a doppeldock command, for scripting and power users.

Same icon or own icon?

One checkbox decides what the Dock shows while the profile is open.

Questions

Which apps does it work with?

Apps built on Electron, which includes many popular desktop apps such as Claude, Slack, Discord, Visual Studio Code, Figma, Signal and draw.io. DoppelDock lists the ones it finds in your Applications folder.

Can I use two Claude accounts at the same time?

Yes. The Claude desktop app is built on Electron, so DoppelDock can give it a second profile, for example Claude Personal next to your work Claude, each with its own sign-in. The same works for Slack, Discord, Visual Studio Code and other Electron apps.

Does it change the original app?

No. With the own icon option, DoppelDock makes a separate copy (it takes almost no extra disk space). Without it, nothing is copied or modified at all.

Where is my second account's data?

Each profile has its own data folder in ~/Library/Application Support/DoppelDock. Things an app keeps elsewhere in your home folder are shared.

Why does macOS warn about the download?

Apps downloaded from the web must be notarized by Apple to open without a warning, and DoppelDock isn't (yet). Allow it once in System Settings › Privacy & Security › Open Anyway. Homebrew and the Terminal line build DoppelDock on your own Mac instead, so there is no warning.

How do I know the download is genuine?

Every DMG is built by DoppelDock's public release workflow from the tagged source code, and GitHub records signed build provenance for it. With the GitHub CLI, run gh attestation verify DoppelDock.dmg -R ZarinLab/doppeldock. Each release also lists the DMG's SHA-256 checksum.

How do I update or uninstall it?

To update, quit DoppelDock and install it again the same way: download the new DMG, run brew upgrade doppeldock && doppeldock install, or run the Terminal line. To uninstall, remove your profiles in DoppelDock, then move DoppelDock to the Trash.

Is it affiliated with the apps it works with?

No. DoppelDock is an independent, unofficial tool. App names are trademarks of their owners. Check each app's terms of use before using it, especially the own icon option, which makes a modified copy of the app.
