# Code of Conduct

DoppelDock follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept
constructive feedback gracefully, and focus on what is best for the people who
use and build DoppelDock. Harassment, personal attacks, discriminatory language
and publishing others' private information are not acceptable, in issues, pull
requests or anywhere else connected with the project.

## Reporting

If someone's behaviour concerns you, report it privately to the maintainers
through this repository's private reporting form,
[Security › Report a vulnerability](https://github.com/ZarinLab/doppeldock/security/advisories/new);
start the title with "Conduct:". Only the maintainers can see these reports.
They will be reviewed promptly and handled as confidentially as possible.

Maintainers may remove, edit or reject comments, commits, code, issues and
other contributions that don't follow this code, and may temporarily or
permanently ban anyone whose behaviour is harmful, following the enforcement
guidelines of the Contributor Covenant.
